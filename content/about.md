I started hacking when I was thirteen.

Most of my career was in high-frequency trading and in defense. In trading,
I built systems where a few microseconds decided if a trade made money. In
defense, I built systems for networks with no internet connection, where
every package had to be approved before it could run. I wrote the code in
both jobs, and later I ran the teams that wrote it.

Now I teach [courses](/training/) on how AI systems run and how they break.
I also built [Gibson](/products/), the runtime our labs run on. If you want
your agents attacked and fixed before they go to production, I do that as
[consulting](/services/).
